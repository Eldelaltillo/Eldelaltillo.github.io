Sobre mí

¡Hola! Soy Eduardo 👋

Soy Tecnólogo en Desarrollo de Software. Mi enfoque no está en acumular títulos, sino en construir soluciones reales. Aunque estoy buscando mi primera oportunidad en el entorno corporativo, he dedicado mi tiempo a diseñar, programar y desplegar software bajo estándares profesionales.

No me limito a seguir tutoriales; me apasiona resolver problemas reales mediante el código. Mi stack tecnológico y mis focos de práctica son:

Desarrollo Full-Stack: Construyo la lógica de negocio y APIs robustas con Java y Spring Boot, conectándolas con interfaces dinámicas y escalables en Angular y JavaScript.

Entornos Interactivos y Móviles: Creo aplicaciones móviles nativas utilizando Android Studio y diseño mecánicas y físicas de juego en Unity usando C#.

¿Por qué trabajar conmigo? Porque sé trabajar de forma autónoma. Mis proyectos de desarrollo propio reflejan mi capacidad para investigar documentación técnica, resolver bugs complejos por mi cuenta y estructurar código limpio y mantenible. Estoy listo para trasladar esta disciplina y capacidad de autoaprendizaje a tu equipo de desarrollo.

Mis Proyectos

Una selección de mis trabajos más recientes en desarrollo web, móvil y automatización.

Integra un sistema accesible e incluyente mediante animaciones y soporte para lengua de señas, optimizando el renderizado 3D y la lógica de interacción dentro del entorno virtual.

Unity C# VR Integration 3D Modeling

Registro de Comidas Colegio

Sistema web full-stack enfocado en el control logístico y trazabilidad del comedor institucional. Aplicación móvil Android nativa para comercio electrónico de artículos tecnológicos. Implementa arquitectura modular para la gestión de carrito de compras, catálogo persistente con sección de favoritos, sistema local de notificaciones y administración de perfiles de usuario.

Android SDK Java SQLite / Room Material Design

Spotify Playlist Orchestrator

Sistema desatendido desarrollado en Python bajo una arquitectura Orchestrator/Manager que automatiza la creación y actualización de playlists dinámicas en Spotify. Python Spotipy (Spotify Web API) Last.fm API Tkinter / Win32 API OAuth 2.0

Python EXIF Data Parser OS / I/O Modules
